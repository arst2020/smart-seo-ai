# Smart SEO AI

افزونه سئوی وردپرس با هوش مصنوعی — جایگزین Rank Math (عنوان/متا، Schema و سازنده Schema، نقشه سایت، ریدایرکت و لاگ 404، بردکرامب، انتقال از Rank Math/Yoast، AEO، اتصال سرچ کنسول، ورود گزارش Ahrefs، پشتیبانی WooCommerce و چندزبانه).

سرویس‌های هوش مصنوعی: Gemini، Groq، Cloudflare Workers AI، Mistral، OpenRouter، DeepSeek، Ollama و هر API سازگار با OpenAI — با جابه‌جایی خودکار به سرویس پشتیبان.
