# Smart SEO AI

افزونه سئوی وردپرس با هوش مصنوعی — جایگزین کامل Rank Math، سازگار با WooCommerce، سایت‌های چندزبانه، المنتور و آوادا.
ساخت **NFPSMART** — نویسنده **ARST**. مجوز: GPLv2 یا بالاتر.

## امکانات

**سئوی پایه (جایگزین Rank Math)**
- عنوان و توضیحات متا، کلمه کلیدی، canonical، robots (noindex/nofollow)، Open Graph و Twitter Card
- نقشه سایت XML، بردکرامب، ریدایرکت‌ها و لاگ خطای 404
- انتقال تنظیمات و داده از Rank Math و Yoast (در فیلدهای همان‌ها هم می‌نویسد)
- نقشه سایت ویدیو و اخبار (Google News)
- سئوی محلی: چند شعبه، Schema کسب‌وکار محلی برای هر شعبه، فایل KML، کد کوتاه آدرس/ساعت/نقشه
- ارسال فوری برای ایندکس: Google Indexing API و IndexNow، تکی، دسته‌جمعی یا خودکار
- نقش‌ها و دسترسی: کنترل دسترسی هر نقش کاربری به بخش‌های افزونه

**Schema**
- Schema خودکار (مقاله، محصول، سازمان، بردکرامب، FAQ و…) و سازنده Schema
- Schema گروهی محصولات WooCommerce و جلوگیری از Schema تکراری

**بررسی و گزارش**
- بررسی سئوی همه صفحه‌ها (مشابه Rank Math) با امتیاز، بررسی صفحه زنده (H1 تکراری، لینک داخلی، تعداد کلمات)
- بررسی فنی کل سایت: canonical اشتباه/تکراری و viewport، با اصلاح گروهی و قابل برگشت
- گزارش کامل هر صفحه + دکمه «بررسی مجدد» و «بررسی مجدد همه»
- اتصال سرچ کنسول (حساب سرویس یا OAuth): ایندکس، کلیک/نمایش/CTR/جایگاه، فرصت‌ها؛ یا وارد کردن CSV خروجی سرچ کنسول
- ردیابی رتبه کلمات کلیدی (تاریخچه روزانه از سرچ کنسول، تغییرات و نمودار)
- ورود گزارش Ahrefs (پلن رایگان)، بخش AEO (بهینه‌سازی برای موتورهای پاسخ)

**هوش مصنوعی**
- پیشنهاد عنوان/متا، بازنویسی محتوا، متن جایگزین تصاویر (alt)، لینک‌سازی داخلی
- سرویس‌ها: Gemini، Groq، Cloudflare Workers AI، Mistral، OpenRouter، DeepSeek، Ollama و هر API سازگار با OpenAI — با جابه‌جایی خودکار به سرویس پشتیبان و جایگزینی خودکار مدل‌های بازنشسته

**استودیو محتوا**
- ایده از سرچ کنسول، سرفصل قابل ویرایش، نوشتن بخش‌به‌بخش، انتخاب تصویر از کتابخانه رسانه
- خروجی صفحه کامل یا یک بخش (HTML)، پیش‌نویس گوتنبرگ/المنتور/آوادا
- توضیحات محصول و متن دسته، تقویم انتشار، پروفایل برند
- طراح صفحه با هوش مصنوعی برای المنتور و آوادا

**امنیت و کنترل**
- هیچ تغییری خودکار اعمال نمی‌شود؛ هر تغییر با تأیید مدیر و در «تاریخچه» قابل برگشت
- بررسی nonce و سطح دسترسی در همه درخواست‌ها

## نصب
1. آخرین نسخه را از شاخه `release` دانلود کنید (Code › Download ZIP) یا فایل zip پوشه `smart-seo-ai` را بسازید.
2. وردپرس › افزونه‌ها › افزودن › بارگذاری.
3. در «Smart SEO AI › تنظیمات» کلید یکی از سرویس‌های هوش مصنوعی را وارد کنید.
